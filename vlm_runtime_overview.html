KIE VLM 작동 원리

사용자가 정의한 schema와 문서 이미지를 LangChain structured output으로 전달하고, full-page field와 region field를 그룹 단위로 나누어 추출한 뒤 하나의 결과로 병합합니다.

React UI FastAPI LangChain Structured output Batch parallel

1. 데이터 흐름

Upload 단일 문서 또는 batch 문서를 업로드합니다. PDF/image는 page image로, DOCX/PPTX는 LibreOffice PDF 변환 후 page image로 저장합니다.
↓
Schema fields는 key_name, description, output_format, region_id를 가집니다. regions는 schema 최상위에 상대 좌표로 저장됩니다.
↓
Grouping region_id가 없는 fields는 full-page group 1회, region_id가 있는 fields는 사용 중인 region별 group 1회로 분리합니다.
↓
Validation and save 모델 응답은 schema key만 보존하고 타입, 누락, 경고를 검증해 SQLite와 export payload에 저장합니다.

2. VLM 호출 단위

Full-page group

전체 page image를 입력합니다. region_id가 없는 fields를 한 번에 추출합니다.

Region group

region 외부를 흐리게 만든 context image와 crop image를 함께 입력합니다. 같은 region_id를 쓰는 fields를 한 번에 추출합니다.

Structured output

LangChain with_structured_output이 동적 JSON schema를 강제합니다. VLM이 JSON 문자열을 임의로 출력하는 방식이 아닙니다.
VLM 호출 수 = full-page field가 있으면 1 + 사용 중인 region 수
Batch 처리 batch는 문서 단위 job으로 나뉘며 BATCH_MAX_WORKERS 범위에서 병렬 실행합니다.
Review UI batch item을 선택하면 좌측 문서와 우측 결과 테이블이 같은 job 기준으로 갱신됩니다.
Export 단일 result는 JSON/CSV로, batch는 모든 item을 합친 JSON/CSV로 다운로드합니다.
Region 재사용 하나의 region을 여러 fields가 공유하므로 배치 처리에서도 같은 위치 기준을 유지합니다.
