자동화 흐름

1

문서 업로드

PDF, 이미지, DOCX, PPTX, XLSX를 목적에 맞게 업로드합니다.

2

원본 보존 및 변환

LibreOffice/PyMuPDF로 preview를 만들고, 원본 기반 HTML 정보를 추출합니다.

3

Schema 기반 KIE

필드 설명과 선택 region을 VLM structured output에 전달해 필요한 값만 추출합니다.

4

검토 및 Export

결과를 수정/검토한 뒤 batch 단위 CSV 또는 JSON으로 내려받습니다.

기능 모듈

Raw Data Extractor

Office/PDF 원문을 PDF preview와 안전한 HTML 렌더링으로 변환합니다.

Key Information Extractor

사용자 schema, region, VLM structured output으로 필요한 값만 추출합니다.

OCR

단순 OCR 파이프라인을 추가해 검색 가능한 텍스트를 빠르게 생성합니다.

Intelligence Parse

문서 구조와 의미 단위로 표, 섹션, 엔티티를 지능적으로 분리합니다.

Frontend React, Vite, TypeScript, split viewer, batch sidebar
Backend FastAPI, SQLAlchemy, SQLite WAL, background workers
Document LibreOffice, PyMuPDF, mammoth, openpyxl, python-pptx
VLM LangChain structured output, region crop, masked context
